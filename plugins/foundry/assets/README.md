| [skill-dark.svg](skill-dark.svg) | Workflow icon on a dark tile |

Each file has a 128 × 128 view box and an opaque background. Shapes use fixed
colors and scale without a font dependency. Each image includes a title and
text description. There are no linked images, scripts, external styles or
embedded raster data.

The package mark uses three horizontal bars and one upright. The workflow icon
uses a central tile within a connected grid. The light and dark variants share
their geometry; theme selection changes only colors and descriptive text.
